Correct answers and completed actions need different evaluations

Answering a deadline question from a document differs from adding that deadline to a calendar. The first requires a correct date; the second also requires the correct destination and stored content. Decide what artifact or state counts as completion before choosing an agent evaluation.

GAIA and OSWorld, available by March 2025, illustrate that distinction. This is a comparison of task definitions, not a ranking of their scores.

Questions with tools and actions in an environment

The first GAIA paper introduces questions requiring reasoning, browsing, multimodal handling, and tool use. Its questions and answers probe capabilities relevant to general assistants.

The first OSWorld paper covers real web and desktop applications and file operations. Tasks have initial-state configurations and execution-based evaluation scripts. The result is checked beyond the plausibility of a written response.

A success rate on one benchmark cannot be read as a success rate on the other's work. Check how closely the environment and completion criteria match the intended delegation.

For calendar entry, inspect the saved event

Turn the deadline example into a hypothetical test. Supply a document with a date and time and a calendar with existing events. Define success as exactly one new event saved to the correct calendar at the specified date and time.

A completion message is insufficient. Wrong calendars, shifted times, duplicate events, and unsaved drafts represent distinct failures. Decide beforehand whether missing time information should prompt a question.

Record the document, initial data, application version, and permitted actions. Different calendar state or access rights can change the task. Reproducible conditions help determine whether a revision improved performance.

Separate grading evidence from debugging evidence

The final state can establish whether the event was saved correctly. Investigating whether the agent misread the document or selected the wrong day may require intermediate actions. Grading success and diagnosing failure use different information.

For adoption decisions, retain failure categories and human corrections alongside aggregate scores. Use public benchmarks to understand candidates, then define completion for the actual work. A passed evaluation should communicate precisely what delegation it supports.
