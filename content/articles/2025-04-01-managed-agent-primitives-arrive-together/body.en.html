Check what an agent platform actually manages

In March 2025, OpenAI announced the Responses API and Agents SDK, while AWS made Bedrock multi-agent collaboration generally available. Both supplied development components, but not identical operational responsibilities. Separate tool execution, agent coordination, and application operation when comparing them.

This article examines those announcements at the time, asking what the service handles and what the application team runs.

Hosted tools and an embedded SDK are different components

OpenAI's March 11 announcement added web search, file search, and computer-use tools through the Responses API and separately introduced the open-source Agents SDK. The SDK addressed agent configuration, handoffs, input/output checks, and tracing.

Using an SDK in an application does not establish that the provider manages its deployment, user authentication, or business-data storage. Distinguish API-provided tools from embedded orchestration and identify where each part of the application runs.

Bedrock supplied supervisor coordination as a service capability

AWS's March 10 announcement described supervisor-led decomposition and a routing mode that sends simple requests directly to a specialist. Complex or unclear requests still trigger supervisor coordination.

This makes part of the coordination configurable within the service. It does not guarantee correct routing from ambiguous role descriptions or define the meaning of a connected business API. General availability does not establish correctness for every application.

Compare remaining implementation and operation on one workflow

Imagine internal support answering product-use questions and order-status requests. One needs document retrieval; the other needs an order API. Begin with one agent, then compare a specialist configuration on the same questions if division of work is justified.

Check answer correctness, routing mistakes, and API failure behavior. Also record which runtime the team maintains, which records it can retrieve, and which settings it controls. Latency and usage cost can change when multiple agents participate.

The practical lesson from these launches is to identify component responsibilities. A small workflow exposes what remains to implement and operate, making the reasons for managed features or application-controlled execution concrete.
