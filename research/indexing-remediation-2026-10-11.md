# インデックス未登録への対応（2026年10月11日）

## 目的と公開変更

取得可能な公開サイトで未登録が続くため、確認できた不具合を修正し、記事の制作主体と検証可能性を具体化する。Search Consoleのプロパティを削除・再登録して検索評価をリセットする方法は採用しない。

| 前回の指摘 | 今回の対応 | 完了の判断条件 |
| --- | --- | --- |
| 旧favicon・OG画像の404 | `/favicon.ico`と`/assets/og-twitter-card.png`を現行資産と同じバイトで生成 | ローカル検証と公開GETで200、現行資産とハッシュ一致 |
| NewsArticle.imageがロゴ | 記事schemaからimageを除外。出版社のlogoとSNS共有画像は用途を分けて維持 | 全72記事のschemaにロゴのimageを出さない。本文・canonical・日英対応は保つ |
| 編集責任の具体性 | 日英Aboutに実在の管理者アカウント、公開プロフィール、AI使用範囲を記載 | 架空の資格や試験実績を追加せず、公開ページとプロフィールが対応 |
| 記事の根拠を追いにくい | 全72記事に当該言語の本文ソースと記事ディレクトリの変更履歴を追加 | 全記事のリンクが当該記事を指す。共通Aboutだけへの誘導ではない |
| 独自分析と実証の区別 | 日英編集方針に、問い→具体例→比較条件→判断→限界、製品挙動・引用実験・想定例の区別を明記 | 論文の測定を著者の実験と称さない。引用や長さだけで品質合格としない |
| lastmodと今回変更の不一致 | 今回の実質的な記事メタデータ・編集案内の更新日時を保持。本文のGit更新との新しい方を使う | schema・可視更新日・サイトマップが実質更新に対応。ビルドだけで日付を進めない |
| 公開された版の検証不足 | `pnpm verify:public`とDeploy Siteの公開照合を追加 | 正規102ページ、3 XML、robots、旧/現行資産等、計112取得をビルド成果物と完全一致で照合 |
| Google側の処理情報が古い | 既存プロパティでサイトマップ・代表URLを再確認 | 最終読込・クロール・登録状態を同じ日時で記録。送信受付と登録を別に扱う |
| 非正規URLが200 | 内部リンク・サイトマップ・canonicalを正規URLに一致させた状態を維持して検証 | GitHub PagesでURL別のHTTP301を追加する設定は今回未確認。インフラ移行を行って解決済みとしない |

Google公式の[Article説明](https://developers.google.com/search/docs/appearance/structured-data/article)では、image等に必須プロパティはなく、記事内容を表す画像を使うとしている。今回はロゴを記事画像として扱わない方法を選んだ。[生成AI方針](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content)に沿い制作方法と根拠を明示する。[プロパティの追加](https://support.google.com/webmasters/answer/34592)は検索上のサイト状態を変更する操作ではない。

## 記事の価値を確認する条件

記事の比較・解釈は36記事の既存の論証レビューに記録されている。今回それを公開実験の証拠と呼び替えず、全記事から本文と履歴を辿れるようにした。技術修正だけで全記事の独自価値がGoogleに評価されたと判断しない。

特に再クロールを求めたHACW記事は、CLEO、Pista、Workspace Agents、CHAPを比較して協働環境の設計仮説を示す。引用した参加者数や比較条件は他者の研究結果で、HACW全体の有効性を実証したものではない。実行経路評価記事は、道具の呼出し、許可、保存結果を分けて確認する比較を持つが、説明の予約変更例を実運用の成功例として扱わない。Jev記事は分類・生成・確率付き判断を比較するが、ベンダーの結果を自社の成功率と読み替えない。

取得後も未登録が継続する場合は、少数の代表記事について、検索意図に合う問い、一次資料からの追加的な判断、再現可能な比較条件、反証・限界、実際の利用・検証を裏付ける記録を確認する。新しい測定を実施していない記事に測定実績を足さない。公開情報の紹介以上の価値を競合との比較で証明することは、今回の配信確認とは別に残る。

## 操作と検証の境界

ローカルで`pnpm build`、`pnpm validate`、`git diff --check`を実施。公開検証ツールをローカルHTTPサーバーに向け、112/112件の一致を確認した。リモートpush・Actions・公開結果は公開後の記録で補完する。

GSCの登録済み件数はGoogle側の選択結果で、コード変更から即時の改善を保証できない。新たな外部リンク、実在の著者の資格、製品の実運用結果は今回作成していない。DNS・ホスティングの移行、GSC削除、検証トークン削除、Google Indexing APIの一般記事への使用、継続監視の自動化は実施しない。

既存のローカル監査データ、アカウント情報を含み得るGSC画面、作業中の未追跡ファイルは、この変更のコミットへまとめて追加しない。
