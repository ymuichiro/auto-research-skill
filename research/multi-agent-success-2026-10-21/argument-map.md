# マルチエージェントの成功条件：論証設計

調査日・記事の資料締切：2026-10-21。ユーザー指定の論文整理を中心とするテーマ記事。新しい一週間の出来事を装う記事ではない。公開操作は依頼されていないため、記事は draft のままローカルプレビューする。

## 問いと主張

- 問い：精度低下や費用増があり得る中で、どの仕事ならマルチエージェントを試す根拠があり、研究で何が改善したか。
- 主張：独立した探索、生成と検証の分離、多様な候補の選別・統合が実際に増える仕事には成功例がある。採用判断には、その構造が単一エージェントの不足を補い、連絡・統合に使う予算を上回るかを同じ課題で検証する必要がある。

## 必要な主張と根拠

1. **役割を分けた比較そのものが有効な例がある。** AgentCoder v3 §4.7 Tables 6–8。GPT-3.5-turbo、単一会話でコード・テストを生成する構成と分離構成。HumanEval pass@1 71.3→79.9、MBPP 79.4→89.9。生成テスト精度も比較。実行担当は Python スクリプトであり三つの LLM ではない。反復・指示・文脈も含む構成差なので人数だけの因果推定とは書かない。
2. **独立に調査できる仕事は並列化と相性がよい。** Kim et al., Nature Machine Intelligence 2026、260構成・6ベンチマーク。Finance Agent 0.349→0.631、相対+80.8%。2025年プレプリントの180構成・+80.9%と混ぜない。Anthropic 2025は実装事例、査読論文・同予算比較ではない。+90.2%は社内評価の改善、15倍の比較対象は通常チャット。
3. **回答の多様性を統合する成果と、相互討論の成果を分ける。** MoA v1 Table 2は6提案・3層、LC勝率57.5→65.1。Table 3は2層、6提案、同一モデル56.7と異種モデル61.3。Debate or Voteは7課題で投票が利得の多くを説明。Self-Consistencyを必須対照にする。
4. **成果は正答率以外にも存在する。** Hu et al. 2026の創造性は人間の評定に基づく。GPT-4.1で単一0.253→最良の複数構成0.298。最良構成を選んだ比較、評定の前処理、提案の実装成果ではない点を示す。Co-Scientist v2はAMLの薬剤候補・組み合わせをin vitro検証。単一同予算との実験成果差は未確定。
5. **成功を再現する採用判断は、自分の仕事で比較するところまで必要。** AI Agents That Matterの費用と精度、MASTの引継ぎと検証の失敗を受け、単一・単一反復/投票・分担・分担+統合の比較を筆者提案として示す。モデル、道具、全体予算、試行回数を揃え、失敗を含む費用・時間を測る。

## 著者の解釈と限界

分担名より、渡される新しい情報と検証結果を設計単位にするという判断は本稿の総合的な解釈。全研究を一つの効果量へ統合しない。ベンチマーク、社内評価、評定、実験室での検証を別の成果として表示する。ベンチマークの再実験、実機・本番導入の検証は今回行わない。

## 構成

成果の地図 → コードとテストの分離 → 並列調査 → 候補統合 → 創造的探索 → 科学的仮説と実験 → 討論の追加価値 → 採用対象と比較方法。


## 2026-10-21：依存する工程を持つタスクの追加

ユーザー指定により、単一構成を比較の起点に置きつつ、長い開発や画面操作で成果を出す論文を追加調査した。本文には CAID v2、Agent S2、M1-Parallel、OneFlow と情報ボトルネック分析の5件を追加。追加資料の全体は workflow-paper-review.md と sources.json に保存した。独立した一次資料は28件、本文の参照は17件となった。

新しい論証は、全体が依存していても、実行可能な変更を分離し統合できるCAID型、専門の操作能力を補うAgent S2型、複数の逐次解法を並行させるM1型を区別する。CAIDは同一モデルだが同予算ではない。Agent S2は異種の能力を含む構成の比較。M1は既存の複数構成への改善である。工程数だけを採用理由にしない。

構成は10節：成果の地図 → AgentCoder → CAIDと単一の比較基準 → 並列調査 → 画面操作・逐次引継ぎ・複数解法 → 候補統合 → 創造的探索 → 科学的仮説 → 討論の追加価値 → 採用判断。既存の独立した貢献・統合・確認の挿絵は変更後の論旨にも合うため維持。
