# 記事を書く際のテンプレート

記事の配色、書体、余白、画面幅は共通テンプレートが適用する。
執筆者はタイトル、要約、出典を`meta.json`へ記入し、日本語と英語の本文へ内容だけを書く。
CSSクラス、色指定、ページのヘッダー、共有ボタンを本文に書く必要はない。

## 記事を作る

```sh
pnpm new:article --date 2026-10-12 --slug example-topic
```

`templates/article/body.ja.html`と`body.en.html`から、スタイル指定のない本文雛形を作る。
初期状態は`draft: true`で、通常の公開ビルドには含まれない。
`meta.json`に本文の題名、要約、カテゴリ、タグ、確認した出典を記入する。
本文に`h1`を追加せず、節の見出しは`h2`、小見出しは`h3`にする。

## 本文と図の記述

```html
<section>
  <h2>この記事が答える問い</h2>
  <p>確認した事実と、その条件を記述する。</p>
  <p><a href="一次情報のURL">出典名</a>から何が分かるか説明する。</p>
</section>
```

節の見た目、目次、見出しのリンク、読了目安を自動で付ける。
箇条書きは`ul`、順序のある説明は`ol`、引用は`blockquote`、コードは`pre`と`code`で記述する。
既存の`report-section`なども引き続き使える。

仕組みを図にする場合は、意味のある順序を`figure`内の`ol`で表す。
共通テンプレートがデスクトップでは横方向、狭い画面では縦方向に整える。
比較表は`figure`内の`table`、説明は`figcaption`に記述する。
使える内容構造の例は[visual-blocks.html](../templates/article/visual-blocks.html)にある。
ラベル、条件、出典を残し、見本画像の数値や主張を転載しない。

数値が二列の表で、値がすべて確認済みの数値の場合は、共通テンプレートが棒グラフを追加する。
元の表は残すので、値と単位を確認できる。
未計測などの文字が含まれる表はグラフへ変換しない。

画像には`alt`と元の寸法を指定する。
SVGのグラフには説明と実データを付け、図が示す条件を本文にも残す。
色を指定する必要があるときは、共通デザインで定義した役割を使い、記事固有の配色を作らない。

## 編集中のプレビュー

```sh
PREVIEW_ARTICLE=2026-10-12-example-topic pnpm dev
```

表示されたローカルURLに記事のファイル名を付けて開く。
日本語は`/2026-10-12-example-topic.html`、英語は`/en/2026-10-12-example-topic.html`で確認する。
本文の保存時に再生成し、ブラウザーを更新すると公開時と同じテンプレートで見られる。
このプレビューでは対象の下書きだけを加え、検索エンジン向けに`noindex,nofollow`を設定する。
公開用のビルドでは`PREVIEW_ARTICLE`を設定せず、出典確認が終わった記事だけ`draft: false`にする。

## 確認

本文と英訳の条件、出典、確信度を揃え、`pnpm build`を実行する。
新しい内容構造を使った場合は、ローカルサーバーを起動して`pnpm verify:design`でも確認する。
デザインを調整する必要が出たら、記事ソースではなく共通CSSか生成テンプレートへ反映する。
